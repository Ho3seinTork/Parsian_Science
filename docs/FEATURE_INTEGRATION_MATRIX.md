## Optional external projects

ToolUniverse, Biomni, PaperQA2, GPT Researcher, AI-Scientist-v2, Denario, Docling, Quarto, MLflow, Langfuse and alternate Persian Science projects are evaluation candidates from the brief. This fork has not imported their code as part of the current work. An existing connector or comparable function must not be presented as an integration with one of these projects.

Before adding a candidate: identify the exact revision, license and data/model terms; check the existing equivalent; choose an existing MCP/tool/provider/execution boundary; keep optional dependencies optional; record functional tests and credentials; then update this matrix with actual evidence. Do not transplant a different application's UI.
